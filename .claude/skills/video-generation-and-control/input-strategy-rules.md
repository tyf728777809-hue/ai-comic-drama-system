# 输入策略规则

本文件定义视频生成的输入策略选择规则。

---

## 四种输入策略

### 1. 参考图模式

**定义：** 提供一张参考图，引导视频生成的整体风格和画面构成。

**适用场景：**
- 需要保持特定画风或色调
- 首帧不够稳定，需要额外风格锚定
- 场景复杂度高，需要参考图辅助

**输入要求：**
- 1 张参考图（通常为该 segment 的高质量角色图或场景图）
- 参考图必须与首帧风格一致

**风险：**
- 参考图可能与首帧冲突，导致画面抖动
- 不建议作为主要输入方式

### 2. 首帧模式

**定义：** 仅提供首帧图片，视频从此画面开始延展。

**适用场景（默认策略）：**
- 所有 segment 的基础输入方式
- 首帧质量稳定
- 不需要精确控制尾帧画面

**输入要求：**
- 1 张首帧图片（来自资产阶段的 FF 类型资产）

**优势：**
- 最稳定、最可控的输入方式
- 视频从已知画面开始，减少不确定性

**风险：**
- 尾帧不可控，可能与下一 segment 首帧不衔接

### 3. 尾帧模式

**定义：** 仅提供尾帧图片，视频向此画面收敛。

**适用场景：**
- 需要精确控制该 segment 的结束画面
- 结束画面包含关键剧情信息（如揭示、反转）
- 与下一 segment 的首帧衔接要求极高

**输入要求：**
- 1 张尾帧图片（来自资产阶段的 LF 类型资产）

**风险：**
- 首帧不可控
- 不建议单独使用，通常与首帧模式组合

### 4. 首尾帧组合模式

**定义：** 同时提供首帧和尾帧，视频从首帧过渡到尾帧。

**适用场景：**
- 相邻 segment 衔接要求高的位置
- 需要精确控制起止画面的 segment
- 视频内容包含明确的位置变化或状态变化

**输入要求：**
- 1 张首帧图片 + 1 张尾帧图片
- 首帧和尾帧之间必须有合理的过渡空间

**优势：**
- 最强控制力，首尾都可控
- 衔接稳定性最高

**风险：**
- 如果首尾帧差异过大，可能导致过渡不自然
- 如果首尾帧角色姿态差异过大，可能导致角色变形

## 策略选择决策树

```
对每个 segment：

1. 是否有 approved 的首帧资产？
   ├─ 否 → 阻断，回退资产阶段
   └─ 是 → 继续

2. 是否有 approved 的尾帧资产？
   ├─ 否 → 使用首帧模式
   └─ 是 → 继续

3. 该 segment 与下一 segment 的衔接是否属于高优先级？
   ├─ 否 → 使用首帧模式（默认）
   └─ 是 → 使用首尾帧组合模式

4. 首帧质量是否稳定（无角色变形、场景混乱等问题）？
   ├─ 是 → 不需要额外参考图
   └─ 否 → 考虑添加参考图辅助
```

---

## 高优先级衔接判定

以下情况判定为"高优先级衔接"，应使用首尾帧组合：

| 位置 | 原因 |
|------|------|
| 第一集第一个 segment | 系列开头，必须高质量 |
| 包含反转/爽点的 segment | 关键剧情节点 |
| 场景切换处的 segment | 跨场景衔接难度高 |
| 倒数第二集结尾 | 系列悬念最高点 |
| 用户指定的关键 segment | 用户需求优先 |

## 输入策略验证

选定策略后，检查以下条件：

| 检查项 | 标准 | 级别 |
|-------|------|------|
| 首帧资产文件是否存在 | 文件路径可访问 | fail |
| 首帧资产 quality_check = pass | 资产阶段已确认质量 | fail |
| 首尾帧组合时，两帧差异是否合理 | 角色位置和姿态变化不超过合理范围 | fail |
| 参考图风格是否与首帧一致 | 不冲突 | warning |
| 输入图片尺寸是否符合模型要求 | 符合模型规格 | warning |
