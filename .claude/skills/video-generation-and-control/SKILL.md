# Skill：video-generation-and-control

## 适用场景

当 video-production-agent 需要执行以下工作时使用本 skill：
- 从 segment 任务和图片资产生成视频 prompt
- 为每个 segment 选择输入策略（参考图/首帧/尾帧/首尾帧组合）
- 组织视频生成任务记录
- 判断生成失败应重试还是回退上游
- 检查视频阶段风险

**不适用**：视频结果归档、确认复盘、审核交接 → 使用 `video-finalization-and-review-handoff`

---

## 核心目标

1. 从已批准生产规划和资产结果稳定生成视频任务
2. 为每个 segment 选择最优输入策略
3. 保证角色一致性、场景连续性、首尾衔接稳定性
4. 精确区分"应重试"和"应回退上游"的问题
5. 提前识别视频阶段失败风险

## 执行步骤

### 第 1 步：读取生产规划和资产交接摘要

读取 segment 总表（status 必须为 approved）。
读取资产阶段交接摘要，确认可用资产清单。

确认以下信息：
- 总 segment 数量和编号
- 每个 segment 的 key_visual、shot_type、camera_movement、transition_in、transition_out
- 交接摘要中每个 segment 的首帧/尾帧资产路径
- 交接摘要中标注的连续性风险

### 第 2 步：检查输入是否足够做视频生成

对每个 segment 检查：

| 检查项 | 标准 | 级别 |
|-------|------|------|
| segment 是否有 key_visual 描述 | 描述不为空 | fail |
| segment 是否有首帧资产 | 首帧文件路径存在 | fail |
| 首帧图片是否可用 | 文件实际存在 | fail |
| camera_movement 是否定义 | 不为空 | fail |
| 尾帧资产是否存在 | 交接摘要中有记录 | warning |

如果有阻断型缺失 → 停止，输出缺口清单，要求主控回退到资产阶段补全。
如果有非阻断缺失 → 标记为"待确认项"，继续推进。

### 第 3 步：为每个 segment 生成视频 prompt

参照 `video-prompt-rules.md`，将 segment 视觉规格转化为视频生成 prompt。

prompt 必须包含：
- 场景描述：地点、环境、光线
- 角色描述：谁在画面中，做什么
- 动作描述：具体的运动和变化
- 镜头运动：推/拉/摇/移/固定
- 情绪基调：整体情绪走向
- 连续性提示：与前后 segment 的关联
- 限制项：需要避免的画面错误

### 第 4 步：为每个 segment 选择输入策略

参照 `input-strategy-rules.md`，为每个 segment 选择最优输入策略：

| 策略 | 适用场景 |
|------|---------|
| 参考图模式 | 有高质量参考图，需要风格引导 |
| 首帧模式 | 只需控制起始画面 |
| 尾帧模式 | 需要控制结束画面 |
| 首尾帧组合 | 需要同时控制起止画面，衔接要求高 |

选择依据：
- 所有 segment 优先使用首帧模式（最低风险）
- 相邻 segment 衔接要求高时使用首尾帧组合
- 只在首帧质量不稳定时使用参考图辅助

### 第 5 步：组织视频任务记录

将所有 segment 的 prompt、输入策略、输入资产汇总为视频任务记录。
每个任务包含：任务编号、segment ID、输入资产列表、输入策略、prompt、状态、重试次数、风险、待确认项。

### 第 6 步：做视频风险检查

参照 `video-risk-checklist.md`，对每个任务执行风险检查：

| 检查类别 | 检查内容 |
|---------|---------|
| 角色连续性 | 同角色在不同 segment 视频中是否保持一致 |
| 场景连续性 | 同场景在不同 segment 视频中是否保持一致 |
| 动作衔接 | 相邻 segment 的动作是否能自然接续 |
| 首尾帧衔接 | 首帧和尾帧画面是否与上下 segment 兼容 |
| 输入充分性 | 输入资产是否足够支撑视频生成 |
| Prompt 充分性 | prompt 是否足够明确 |
| 生成失败风险 | 是否存在高概率失败的因素 |

### 第 7 步：判断问题应重试还是回退

参照 `retry-vs-fallback-guide.md`，对每个识别的问题分类：

| 问题类型 | 处理方式 |
|---------|---------|
| 视频 prompt 不够准确 | 调整 prompt，直接重试 |
| 生成结果轻微不达标 | 调整参数，直接重试 |
| 首帧资产质量问题 | 回退到资产阶段修复 |
| 角色外观不连续 | 回退到资产阶段重新生成角色图 |
| scene 设定矛盾 | 回退到生产规划阶段 |

### 第 8 步：必要时给出替代策略

当某个 segment 的输入策略效果不佳时，给出替代方案：
- 当前策略 → 替代策略
- 替代策略的成本和风险
- 预期效果差异

### 第 9 步：输出当前版本结果

每次完成任务组织后输出：
- 当前版本号
- 总任务数和分策略统计
- 当前风险检查结果
- 重试/回退建议
- 当前待确认项
- 建议下一步（继续修正 / 进入定稿整理）

## 约束边界

本 skill **不允许**：
- 擅自修改已 approved 的生产规划
- 擅自修改已 approved 的图片资产
- 越权回写上游正式文件
- 直接承担审核放行职责
- 调用 Dream Maker 或任何执行型生成工具

本 skill **允许**：
- 读取所有项目文件
- 写入视频 prompt 和视频任务文件
- 在任务文件内标注风险和待确认项

---

## 完成标准

执行本 skill 后，必须能明确回答：

1. **当前版本**：视频任务当前版本号和状态
2. **任务完整性**：是否已形成覆盖所有 segment 的完整任务
3. **视频风险**：当前是否还有明显视频风险
4. **重试建议**：哪些问题适合直接重试
5. **回退建议**：哪些问题必须回退上游
6. **下一步**：是继续修正还是进入定稿整理
