# 风险分类指南

本文件定义合规审核中的风险分级标准。

---

## 风险等级定义

### high（高风险）

**含义**：存在明确合规违规，必须阻断，不允许进入下一阶段。

**判定标准**（满足任一即为 high）：

| 条件 | 说明 |
|------|------|
| 明确侵权 | 内容明显侵犯第三方版权或知识产权 |
| 真实人物可辨识 | AI 生成内容中真实人物/明星可辨识 |
| 未经授权使用肖像 | 使用了真实人物照片且无授权 |
| 敏感内容红线 | 触碰政治、暴力、色情等平台红线 |
| 贬损特定群体 | 以负面方式刻画特定群体 |
| 输入来源侵权 | 输入素材明确来自侵权来源 |
| 未成年人不当内容 | 涉及未成年人的不当内容 |

**处理方式**：必须 fail，阻断进入下一阶段。

---

### medium（中风险）

**含义**：存在合规隐患，需修改或增加保护措施，可附条件放行。

**判定标准**（满足任一即为 medium）：

| 条件 | 说明 |
|------|------|
| 相似度存疑 | 角色或场景与已知作品有相似性但无法确定是否侵权 |
| 隐含影射 | 内容可能被解读为影射真实人物但不够明确 |
| 平台规则模糊 | 内容处于平台规则边界，可能被误判 |
| 来源不完全清晰 | 输入素材来源基本合法但缺少完整授权链 |
| 敏感主题但非红线 | 涉及敏感主题但处理方式得当 |

**处理方式**：可 conditional_pass，但必须写清限制条件和修改要求。

---

### low（低风险）

**含义**：理论上存在合规注意点，但不影响当前放行。

**判定标准**（满足任一即为 low）：

| 条件 | 说明 |
|------|------|
| 风格趋同 | 画风与某类作品风格趋同但非模仿 |
| 一般性注意 | 需关注但不足以构成风险的内容 |
| 后续需关注 | 当前无风险但后续阶段可能产生风险 |
| 平台规则变化 | 平台规则可能有调整需关注 |

**处理方式**：记录即可，不阻断放行。

---

## 风险记录字段

每条风险记录必须包含以下字段：

| 字段 | 说明 | 取值 |
|------|------|------|
| risk_id | 风险编号 | RSK-001, RSK-002, ... |
| rule_domain | 所属规则域 | CR-01 到 CR-07 |
| risk_level | 风险等级 | high / medium / low |
| risk_type | 风险类型 | 具体类型描述 |
| description | 风险描述 | 具体文字描述 |
| evidence | 风险证据 | 指向具体内容位置 |
| remediation | 修改建议 | 具体可执行的修改方向 |
| responsible_agent | 建议责任 Agent | 具体 Agent 名称 |
| requires_retrial | 修复后是否需要重审 | true / false |

## 风险等级与结论关系

| high 数量 | medium 数量 | low 数量 | 结论 |
|-----------|------------|---------|------|
| 0 | 0 | 0-3 | pass |
| 0 | 0 | 4+ | conditional_pass |
| 0 | 1-2 | 任意 | conditional_pass |
| 0 | 3+ | 任意 | fail |
| 1+ | 任意 | 任意 | fail |

---

## 风险升级规则

以下情况风险等级自动升级：

| 情况 | 升级规则 |
|------|---------|
| 同一风险在连续两次审核中未修复 | medium → high |
| 用户明确要求关注某类风险 | 按用户要求提升关注级别 |
| 目标平台近期有相关处罚案例 | medium → high（针对同类风险） |
| 输入素材包含水印或来源不明 | low → medium |

---

## 使用规则

1. 每条风险必须按本文件标准分级
2. 不得随意升降级
3. high 级别风险必须给出 remediation
4. risk_id 必须唯一且连续
5. evidence 必须指向审核对象的具体位置
