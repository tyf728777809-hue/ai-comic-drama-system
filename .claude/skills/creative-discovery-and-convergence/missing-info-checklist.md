# 创意信息缺口检查清单

本文件列出创意阶段常见缺失字段，说明每个字段的重要性和缺失时的追问策略。

---

## 检查规则

1. 每轮访谈后必须按此清单检查一次
2. 将每个字段标记为：**已明确** / **部分明确** / **缺失**
3. P0 字段缺失 → 必须继续访谈，不可收敛
4. P1 字段部分明确 → 可收敛但标为待确认
5. P2 字段缺失 → 可在正式设定阶段补充

---

## 字段清单

### P0 — 缺了无法收敛

| 字段 | 为什么重要 | 缺失时怎么追问 |
|------|-----------|---------------|
| 题材类型 | 决定整体方向、受众预期、平台分发策略 | "你觉得这大概属于什么类型？都市？校园？悬疑？还是别的？" 给 3-4 个选项 |
| 风格基调 | 决定叙事节奏、视觉风格、情绪曲线 | "你希望观众看完什么感觉？轻松？紧张？感动？" |
| 故事 premise | 所有后续工作的地基，没有 premise 就没有故事 | "用一句话说，这个故事讲的是什么？" 如果说不清，问核心矛盾 |
| 主角设定 | 主角是叙事视角的核心，缺了无法设计情节 | "主角是什么样的人？大概年龄、性格？" |

**判定规则**：以上 4 个字段任一缺失，判定为"信息不足，需继续访谈"。

### P1 — 缺了影响结构

| 字段 | 为什么重要 | 缺失时怎么追问 |
|------|-----------|---------------|
| 核心钩子 | 决定前 3 秒能不能留住人 | "观众为什么要看下去？最抓人的点是什么？" |
| 人物关系 | 角色互动是短段叙事的主要驱动力 | "主要角色之间是什么关系？有没有矛盾？" |
| 单集时长 | 直接影响叙事密度和拆段方式 | "单集大概多长？15 秒 × 几段？还是更长？" |
| 集数/篇幅 | 影响故事展开深度和节奏规划 | "大概想做几集？有没有粗略的想法？" |
| 目标受众 | 影响叙事策略和传播设计 | "主要做给谁看的？什么年龄段？" |

**判定规则**：以上 5 个字段中 3 个以上缺失，建议继续访谈；1-2 个缺失可收敛但标为待确认。

### P2 — 可后续补充

| 字段 | 为什么重要 | 缺失时怎么追问 |
|------|-----------|---------------|
| 项目名称 | 影响文件命名和对外展示 | "有名字了吗？还是暂定名？" |
| 作品形态 | 竖屏/横屏、单集/系列 | "竖屏还是横屏？单集还是系列？" |
| 主要配角设定 | 配角细节可在剧本阶段展开 | "除主角外，还有谁比较重要？" |
| 世界观规则 | 非架空题材世界观即现实，无需追问；架空题材需确认 | "故事发生在什么样的世界？有特殊设定吗？" |
| 商业目标 | 影响内容策略和传播设计 | "做这个主要目的是什么？涨粉？品牌？纯创作？" |
| 传播目标 | 影响钩子设计和话题点 | "希望观众看完会转发吗？什么理由会转发？" |
| 禁区与边界 | 避免后续返工 | "有什么是你明确不想要的？有没有红线？" |
| 视觉风格暗示 | 影响 AI 生图方向 | "画面风格有想法吗？写实？漫画？国风？" |

**判定规则**：P2 字段缺失不影响收敛，但必须在正式设定文件中标为"待确认"。

---

## 追问策略

### 用户说"都行"或"你定"

- 给 2-3 个具体选项：A 激进型 / B 稳妥型 / C 折中型
- 每个选项说明特点和风险
- 让用户选一个方向，而不是从零开始想

### 用户说"不知道"

- 换个角度问：问感受不问概念
- 给参考锚点："像 XX 那种感觉可以吗？"
- 允许暂标记为待确认，不要卡住

### 用户给的信息互相矛盾

- 直接指出矛盾："你之前说想要轻松风格，但现在说核心冲突是生死抉择，这两个方向有点矛盾"
- 帮用户做选择：哪个优先级更高？
- 记录用户最终选择，放弃被否定的方向

### 用户给的设定太复杂

- 提醒短段叙事的承载力："15 秒一段能承载的信息量有限，X 和 Y 可能需要二选一"
- 建议简化方案
- 如果用户坚持，标为高风险项

---

## 充分度判定

| 状态 | 条件 | 建议 |
|------|------|------|
| 信息不足 | P0 有缺失 | 继续访谈，不收敛 |
| 基本充分 | P0 全满，P1 缺失 ≤ 2 | 可收敛，P1 缺失标为待确认 |
| 充分 | P0 + P1 全满 | 可收敛并进入正式设定整理 |
| 非常充分 | P0 + P1 + 大部分 P2 全满 | 可直接进入定稿阶段 |
