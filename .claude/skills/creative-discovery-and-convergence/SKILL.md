# 创意发现与收敛

## 适用场景

当用户提供了原始创意想法（无论多模糊），需要通过系统化访谈和收敛将其整理为清晰的创意方向时使用。

不适用于正式创意设定输出（由 creative-bible-and-handoff 负责）、剧本写作、资产规划。

## 核心目标

1. 把用户脑子里的模糊创意系统地问出来
2. 把散乱想法整理成一个稳定概念
3. 识别并补齐关键信息缺口
4. 对齐风格、气质和参考方向
5. 提前识别创意层面的叙事风险和生产风险

## 输入

| 输入项 | 来源 | 必需 |
|--------|------|------|
| 用户原始创意表达 | 用户输入 | 是 |
| 项目已有创意记录 | project_data/series/ 或 project_data/episodes/ | 否 |
| 历史创意版本 | project_data/series/versions/ | 否 |
| 用户本轮反馈 | 用户输入 | 否 |
| 项目基本要求 | CLAUDE.md 或主控指令 | 是 |

## 输出

| 输出项 | 文件 | 说明 |
|--------|------|------|
| 创意访谈记录 | `project_data/series/interviews/interview-round-{N}.yaml` | 每轮访谈的整理结果 |
| 创意收敛摘要 | `project_data/series/creative-convergence-v{version}.yaml` | 当前创意方向总结 |
| 创意风险提示 | 收敛摘要内嵌 | 已识别的创意风险 |
| 待确认项 | 收敛摘要内嵌 | 尚未明确的信息 |
| 下轮追问点 | 访谈记录内嵌 | 下一步追问方向 |

## 执行步骤

### 步骤 1：读取已有创意上下文

1. 检查项目中是否已有创意记录文件
2. 如果有，读取最新版本，确认已有哪些信息、哪些仍缺失
3. 如果没有，从零开始，进入首次访谈模式
4. 读取 [missing-info-checklist.md](missing-info-checklist.md) 对照已有信息

### 步骤 2：判断当前信息充分度

1. 按 [missing-info-checklist.md](missing-info-checklist.md) 逐项检查
2. 将信息分为三类：
   - **已明确**：用户已清楚表达
   - **部分明确**：有方向但不够具体
   - **缺失**：尚未涉及
3. 评估当前是否具备收敛条件：
   - 关键字段（题材、风格、主角、premise）均已明确 → 可收敛
   - 关键字段仍有缺失 → 继续访谈

### 步骤 3：做开放式访谈

1. 从 [interview-question-bank.md](interview-question-bank.md) 选取适合当前阶段的问题
2. 访谈原则：
   - 每轮最多问 3-5 个问题，不要一次抛出全部
   - 先问大的、开放的问题，再逐步聚焦
   - 用户回答模糊时，给 2-3 个选项辅助决策
   - 记录用户明确不想要什么，和明确想要什么同样重要
3. 整理本轮访谈记录，包含：
   - 本轮讨论重点
   - 用户偏好
   - 用户反对项
   - 未明确问题
   - 下轮建议追问点

### 步骤 4：补关键缺口

1. 对照 [missing-info-checklist.md](missing-info-checklist.md) 识别缺失字段
2. 按优先级追问：
   - P0：premise、主角、题材、风格（缺了无法收敛）
   - P1：核心钩子、人物关系、单集时长、集数（缺了影响结构）
   - P2：配角、世界观细节、商业目标、禁区（可后续补充）
3. 对于用户难以直接回答的问题，提供选项或参考锚点辅助

### 步骤 5：做参考系和气质对齐

1. 当用户提到"像某作品""像某种感觉"时，按 [reference-alignment-guide.md](reference-alignment-guide.md) 追问：
   - 是像节奏？像气质？像人物关系？像反转机制？还是像世界观？
2. 将模糊的"像"转化为可执行的风格参数：
   - 叙事节奏（快/中/慢）
   - 情绪基调（轻松/紧张/悲情/燃）
   - 视觉风格暗示（日漫/韩漫/国漫/写实/极简）
   - 核心情绪曲线（上升/起伏/反转/平稳）
3. 确认用户对不同参考元素的优先级排序

### 步骤 6：收敛出当前创意摘要

1. 将已收集的信息整理为创意收敛摘要，包含：
   - 一句话概述
   - 题材与风格
   - 核心卖点
   - 角色关系概览
   - 世界观概览
   - 风险提示（来自步骤 7）
   - 待确认项
2. 如果信息不足以收敛，输出"部分收敛摘要"，标明哪些是推测、哪些是确认

### 步骤 7：做创意风险检查

1. 按 [creative-risk-checklist.md](creative-risk-checklist.md) 逐项检查
2. 检查维度：
   - 持续展开能力：这个 premise 能撑多少集？
   - 核心钩子强度：前 3 秒能不能抓住人？
   - 人物关系张力：角色之间有没有天然冲突？
   - 世界观冲突：设定有没有自相矛盾？
   - 短段式适配性：15 秒一段能不能讲得动？
   - AI 生产友好性：角色和场景是否适合 AI 生图？
   - 场景/群像/动作复杂度：是否超出 AI 生产能力？
3. 将风险分为高/中/低三级，高风险项必须在收敛摘要中标红

### 步骤 8：输出当前版本结果

1. 将本轮结果写入文件：
   - 访谈记录 → `project_data/series/interviews/interview-round-{N}.yaml`
   - 收敛摘要 → `project_data/series/creative-convergence-v{version}.yaml`
2. 明确标注当前状态：
   - 如果关键信息仍有缺失 → "需继续访谈"
   - 如果信息基本齐全但有待确认 → "建议进入正式设定整理"
   - 如果用户已口头确认方向 → "建议进入定稿阶段"

## 约束边界

| 约束 | 说明 |
|------|------|
| 不写正式剧本 | 只整理创意方向，不进入剧本写作 |
| 不做 15 秒拆段 | 拆段属于生产规划阶段 |
| 不写分镜方案 | 分镜属于资产生产阶段 |
| 不写资产 prompt | 不涉及生图/生视频提示词 |
| 不调用 Dream Maker | 不涉及任何执行型生产工具 |
| 不代替用户决策 | 提供 2-3 个方向让用户选择 |

## 完成标准

执行完成后，必须能明确回答以下 5 个问题：

1. 当前创意理解到什么程度？ → 已有收敛摘要，标明确认项和推测项
2. 缺什么？ → 待确认项清单已列出
3. 风格和方向是否基本对齐？ → 参考系对齐结果已记录
4. 当前是否还有明显创意风险？ → 风险检查已完成，高风险项已标出
5. 下一步是继续追问还是进入正式创意设定整理？ → 状态判断已给出
