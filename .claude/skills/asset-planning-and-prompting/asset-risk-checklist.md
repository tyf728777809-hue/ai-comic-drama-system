# 资产风险检查清单

本文件定义资产阶段至少要检查的风险项。每次资产清单和 prompt 输出后必须逐项检查。

---

## 检查规则

- 每项检查必须给出 pass / warning / fail
- fail = 阻断，必须修改后才能提交审核
- warning = 非阻断，建议修改
- 检查结果写入资产清单的 `risks` 字段

---

## 一、角色一致性风险

| # | 风险项 | 检查方式 | 级别 |
|---|-------|---------|------|
| 1.1 | 同角色在不同 segment 的外观描述是否一致 | 对比所有 CHAR 类型 prompt 中的角色描述 | fail |
| 1.2 | 同角色服装是否跨 segment 一致 | 检查服装描述是否与 creative-brief 一致 | fail |
| 1.3 | 同角色标志物是否跨 segment 一致 | 检查标志物描述 | fail |
| 1.4 | 角色外观是否与 creative-brief 锁定设定一致 | 对比 visual_keywords | fail |
| 1.5 | 角色数量是否在可控范围 | 单场景角色 ≤ 3 | warning |

---

## 二、场景一致性风险

| # | 风险项 | 检查方式 | 级别 |
|---|-------|---------|------|
| 2.1 | 同场景在不同 segment 的风格是否一致 | 对比所有 BG 类型 prompt 中的场景描述 | fail |
| 2.2 | 场景风格是否与 creative-brief 锁定设定一致 | 对比 visual_style 和 color_palette | fail |
| 2.3 | 场景时间/光线是否与剧情一致 | 检查时间描述与剧本是否匹配 | fail |
| 2.4 | 场景描述是否足够具体 | 不使用"某处""某地"等模糊词 | warning |

---

## 三、首尾帧衔接风险

| # | 风险项 | 检查方式 | 级别 |
|---|-------|---------|------|
| 3.1 | 相邻 segment 的尾帧和下一首帧是否视觉可衔接 | 检查连续性提示是否匹配 | fail |
| 3.2 | 衔接时角色位置是否合理 | 尾帧角色位置与首帧角色位置不矛盾 | fail |
| 3.3 | 衔接时场景是否一致 | 尾帧场景与首帧场景匹配 | fail |
| 3.4 | 衔接时光线/氛围是否自然过渡 | 不出现突然的光线变化 | warning |
| 3.5 | 每个 segment 是否都有首帧和尾帧 | 检查 FF 和 LF 类型资产是否完整 | fail |

---

## 四、Prompt 不充分风险

| # | 风险项 | 检查方式 | 级别 |
|---|-------|---------|------|
| 4.1 | 角色 prompt 是否包含完整外观描述 | 发色+发型+肤色+服装+标志物 | fail |
| 4.2 | 角色 prompt 姿态是否具体 | 不使用"自然""随意"等模糊词 | fail |
| 4.3 | 角色 prompt 表情是否具体 | 不使用"正常""普通"等模糊词 | fail |
| 4.4 | 场景 prompt 是否包含具体地点描述 | 不使用"某处""背景"等模糊词 | fail |
| 4.5 | 首/尾帧 prompt 是否包含完整构图描述 | 包含视角+焦点+角色位置 | fail |
| 4.6 | 每条 prompt 是否有连续性提示 | 检查连续性字段 | fail |
| 4.7 | 每条 prompt 是否有禁止项 | 检查禁止项字段 | warning |
| 4.8 | prompt 是否过长或过短 | 长度在合理范围 | warning |

---

## 五、资产缺失风险

| # | 风险项 | 检查方式 | 级别 |
|---|-------|---------|------|
| 5.1 | 每个 segment 是否有首帧 | FF 类型资产覆盖所有 segment | fail |
| 5.2 | 每个 segment 是否有尾帧 | LF 类型资产覆盖所有 segment | fail |
| 5.3 | 出场角色是否都有角色图 | CHAR 类型资产覆盖所有出场角色 | fail |
| 5.4 | 主要场景是否都有场景图 | BG 类型资产覆盖主要场景 | warning |
| 5.5 | 关键道具是否都有道具图 | 检查剧情关键道具是否有 PROP 资产 | warning |

---

## 六、资产重复风险

| # | 风险项 | 检查方式 | 级别 |
|---|-------|---------|------|
| 6.1 | 是否存在完全重复的资产需求 | 对比所有 asset 的 prompt 描述 | warning |
| 6.2 | 相似资产是否已做复用标注 | 检查相似资产是否标注了 reuse | warning |
| 6.3 | 资产总数是否超出合理范围 | 总资产 ≤ segment 数 × 4 | warning |
| 6.4 | 单 segment 资产是否过多 | 单 segment ≤ 5 张 | warning |

---

## 七、生产成本风险

| # | 风险项 | 检查方式 | 级别 |
|---|-------|---------|------|
| 7.1 | 需新建的资产数量是否合理 | generate 类型资产数量 | warning |
| 7.2 | 复用率是否达标 | 角色图 ≥ 30%，场景图 ≥ 50% | warning |
| 7.3 | 是否有低成本替代方案被忽略 | 检查是否有可复用但未复用的资产 | warning |
| 7.4 | 是否有过于复杂的 prompt | 检查 prompt 中是否包含难以生成的元素 | warning |

---

## 检查结果格式

```yaml
risks:
  checked_at: ""
  overall: "pass"  # pass | needs_fix | fail
  items:
    - id: "1.1"
      category: "角色一致性"
      name: "同角色跨 segment 外观一致性"
      result: "pass"
      details: ""
    - id: "3.1"
      category: "首尾帧衔接"
      name: "相邻 segment 首尾帧衔接"
      result: "fail"
      details: "SEG02 尾帧为室内场景，SEG03 首帧为室外场景，缺少转场衔接"
  must_fix:
    - "3.1: SEG02-SEG03 首尾帧衔接缺失"
  suggestions:
    - "7.2: 角色图复用率 20%，低于目标 30%"
```
