# 视频风险检查清单

本文件定义视频阶段至少要检查的风险项。每次视频任务组织后必须逐项检查。

---

## 检查规则

- 每项检查必须给出 pass / warning / fail
- fail = 阻断，必须解决后才能提交审核
- warning = 非阻断，建议处理
- 检查结果写入视频任务文件的 `risks` 字段

---

## 一、角色连续性风险

| # | 风险项 | 检查方式 | 级别 |
|---|-------|---------|------|
| 1.1 | 同角色在不同 segment 视频中是否保持外观一致 | 对比 prompt 中角色描述是否一致 | fail |
| 1.2 | 同角色在不同 segment 视频中是否保持服装一致 | 检查服装描述是否与 creative-bible 一致 | fail |
| 1.3 | 首帧角色外观是否与首帧资产一致 | 检查 prompt 角色描述是否匹配首帧 | fail |
| 1.4 | 角色标志物是否跨 segment 一致 | 检查配饰、纹身等描述 | fail |
| 1.5 | 单场景角色数量是否超过 3 个 | 检查 prompt 中的角色数量 | warning |

---

## 二、场景连续性风险

| # | 风险项 | 检查方式 | 级别 |
|---|-------|---------|------|
| 2.1 | 同场景在不同 segment 视频中是否保持一致 | 对比 prompt 中场景描述 | fail |
| 2.2 | 场景风格是否与首帧资产一致 | 检查光线、氛围描述 | fail |
| 2.3 | 时间/光线是否与剧情一致 | 检查时间描述与剧本是否匹配 | fail |
| 2.4 | 场景过渡是否自然 | 相邻 segment 场景变化是否合理 | warning |

---

## 三、动作衔接风险

| # | 风险项 | 检查方式 | 级别 |
|---|-------|---------|------|
| 3.1 | 相邻 segment 的动作是否能自然接续 | 尾帧动作与下一首帧动作是否兼容 | fail |
| 3.2 | 单个 segment 的动作描述是否过多 | 15 秒内不宜超过 2 个主要动作 | warning |
| 3.3 | 动作描述是否与镜头运动配合 | 推镜头配合前进动作，拉镜头配合后退 | warning |
| 3.4 | 动作是否可被视频模型稳定生成 | 避免复杂打斗、快速转身等 | warning |

---

## 四、首尾帧衔接风险

| # | 风险项 | 检查方式 | 级别 |
|---|-------|---------|------|
| 4.1 | 每个 segment 是否都有首帧输入 | 检查任务记录中首帧字段 | fail |
| 4.2 | 使用首尾帧组合时，两帧差异是否合理 | 角色位置和姿态变化不超过合理范围 | fail |
| 4.3 | 首帧与上一 segment 尾帧是否视觉兼容 | 检查连续性提示是否匹配 | fail |
| 4.4 | 尾帧与下一 segment 首帧是否视觉兼容 | 检查连续性提示是否匹配 | fail |
| 4.5 | 首尾帧组合时光线是否一致 | 不出现突然的光线变化 | warning |

---

## 五、输入不足风险

| # | 风险项 | 检查方式 | 级别 |
|---|-------|---------|------|
| 5.1 | 所有 segment 是否都有首帧输入 | 任务记录覆盖所有 segment | fail |
| 5.2 | 首帧资产文件是否实际存在 | 检查文件路径 | fail |
| 5.3 | 首帧资产 quality_check 是否通过 | 检查资产阶段质量记录 | fail |
| 5.4 | 高优先级衔接 segment 是否有尾帧输入 | 检查关键 segment 是否有尾帧 | warning |
| 5.5 | 输入图片尺寸是否符合视频模型要求 | 检查图片规格 | warning |

---

## 六、Prompt 不充分风险

| # | 风险项 | 检查方式 | 级别 |
|---|-------|---------|------|
| 6.1 | 场景描述是否具体 | 包含地点+光线+氛围 | fail |
| 6.2 | 角色描述是否与首帧一致 | 外观、位置、朝向匹配 | fail |
| 6.3 | 动作描述是否具体可执行 | 不使用模糊词 | fail |
| 6.4 | 镜头运动是否明确 | 与 camera_movement 一致 | fail |
| 6.5 | 情绪走向是否标注 | 有明确起止情绪 | fail |
| 6.6 | 连续性提示是否存在 | 每条 prompt 有连续性提示 | fail |
| 6.7 | 限制项是否完整 | 至少包含通用限制项 | warning |

---

## 七、生成失败高风险

| # | 风险项 | 检查方式 | 级别 |
|---|-------|---------|------|
| 7.1 | 单画面角色是否超过 3 个 | 检查 prompt 中的角色数量 | warning |
| 7.2 | 是否有复杂动作编排 | 多人交互、快速运动 | warning |
| 7.3 | 是否有需要精细微表情的画面 | 视频模型不擅长微表情 | warning |
| 7.4 | 首尾帧角色位置差异是否过大 | 可能导致过渡不自然 | warning |
| 7.5 | 是否有文字/字幕叠加需求 | 视频模型不擅长文字 | warning |
| 7.6 | 历史 segment 重试次数是否已达上限 | 同一 segment 重试 ≥ 3 次 | warning |

---

## 检查结果格式

```yaml
risks:
  checked_at: ""
  overall: "pass"  # pass | needs_fix | fail
  items:
    - id: "1.1"
      category: "角色连续性"
      name: "同角色跨 segment 外观一致性"
      result: "pass"
      details: ""
    - id: "4.3"
      category: "首尾帧衔接"
      name: "首帧与上一尾帧兼容性"
      result: "fail"
      details: "SEG03 首帧为室内场景，SEG02 尾帧为室外场景，缺少转场过渡"
  must_fix:
    - "4.3: SEG02-SEG03 首尾帧衔接不兼容"
  suggestions:
    - "7.2: SEG05 动作编排较复杂，建议简化"
```
