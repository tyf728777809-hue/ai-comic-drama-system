# Assistant Workflow SOP

这份文档定义你和助手的协作边界。目标不是让助手替你拍板，而是让它稳定地做对该做的事。

## 总原则

1. 助手可以起草、整理、对照规则、补结构、查缺口。
2. 助手不能替你拍板创意方向、业务取舍、合规放行。
3. 任何正式产物都必须落文件，不能只停留在聊天里。
4. 任何阶段都不能因为“差不多”跳过审核。

## 你负责什么

- 决定项目方向、受众、风格、商业目标
- 确认创意锁定项和边界
- 确认是否接受业务修改建议
- 确认是否接受合规整改路径
- 决定是否继续投入高成本生成

## 助手负责什么

- 按 `.agents/agents/` 选正确角色
- 按 `.agents/skills/` 组织产出结构
- 按 `schemas/` 和 `templates/` 补齐正式文件
- 在推进前提醒缺失文件、缺失审核和阻断项
- 在失败时明确回退到哪一层

## 什么时候助手必须停下来问你

- 创意方向出现互相冲突的要求
- 新需求会改动已锁定设定
- 审核结论是 `fail`
- 合规存在高风险项
- 上游未 approved，但你要求继续下游
- 成本明显上升但收益不明确

## 什么时候助手可以直接继续

- 只是把已有内容整理成正式文件
- 只是按已批准上游补齐下游结构
- 只是把缺失字段补成待确认项
- 只是跑 `validate` / `status` / `sync-compat`

## 阶段协作节奏

### 创意定义

- 你给方向和边界
- 助手补 creative-bible 草稿
- 你确认核心钩子、主角、世界观和禁区

### 剧本开发

- 前提是 creative-bible 已放行
- 助手补 synopsis、episode-plan、script
- 你确认叙事方向、节奏和关键情绪点

### 生产规划

- 前提是 script 已放行
- 助手补 segments 和单段任务文件
- 你确认拆段是否合理、是否真的可做

### 资产生产

- 前提是 segments 已放行且资产前合规已通过
- 助手先补视频一致性资产包：核心角色三视图、表情表、姿态表、场景母版、UI / 道具规范
- 助手再补 asset-manifest、asset-prompts、asset-index、asset-archive
- 精品漫剧不得只用单张角色参考图直接进入视频；缺少三视图、表情表、姿态表、场景母版或 UI 规范时，必须退回资产规划补齐
- 你决定是否继续投入生图成本

### 视频生产

- 前提是对应 segment `can_start_video = true`
- 助手补 video-prompts、video-tasks、video-tasks-final、video-archive
- 你决定是继续重试还是回退上游

## 推荐指令模板

- “以主控 Agent 的视角检查当前项目阶段和缺口。”
- “以创意开发 Agent 的规则整理正式 creative-bible，不要进入剧本阶段。”
- “以业务审核 Agent 的标准，给这个文件出正式审核报告。”
- “只做 schema 对齐和文件化，不改内容方向。”
- “按现有 approved 上游，把 ep01 的生产规划文件补齐。”

## 禁止用法

- “直接帮我全部自动跑完。”
- “先跳过审核，后面再补。”
- “创意还没锁，先去写 prompt。”
- “就按你的判断直接定稿。”
